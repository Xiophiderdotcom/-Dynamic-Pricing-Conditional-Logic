
3. Activate the plugin from the WordPress Admin → Plugins.
4. Create the required pages:

- **Book a Shoot** → add shortcode:
  ```
  [abs_booking]
  ```

- **Agent Portal** → add shortcode:
  ```
  [abs_portal]
  ```

5. (Optional) Add your Google Maps API key in plugin settings for address autocomplete.

## Shortcodes

| Shortcode       | Description              |
|-----------------|--------------------------|
| `[abs_booking]` | Displays the booking form |
| `[abs_portal]`  | Displays the agent portal |
